# 七表同步与审计

调用前读取当前 kdocs 的 `references/sheet/worksheet.md` 和 `references/sheet/data.md`；本说明是业务约束，接口参数以安装版本为准。Windows 中文参数使用 Python/Node 生成 UTF-8 无 BOM JSON，再 `--file` 传递。

## 读取与计划

1. `kdocs-cli sheet get-sheets-info file_id=<id>` 获取名称、真实 sheetId、rowTo、colTo。不得写死 sheetId。
2. 对汇总、电解铜、电解镍、锌锭、锡、钴、碳化钨读取 `0..rowTo`，较大表分块读完，不能只看最后一行。`get-range-data` 使用 `worksheet_id` 与 `range:{rowFrom,rowTo,colFrom,colTo}`。
3. 先按表头定位列：汇总为日期、六品种、备注；分表为日期、价格、备注。确认表头单位。缺表、列变化或单位不符时停止写该表并报告。
4. 规范日期（日期公式、Excel序列、显示日期）后按日期关联；检查每表重复日期、日期覆盖、空值有无失败说明、数值合法性、汇总/分表一致。历史内部一致不等于逐日报价已重新向来源验证；报告应明确范围。
5. 当天不存在：扫描所有非空单元格后在最后实际占用行之后追加。当天只有一行：价格、报价日期和备注全部相同才跳过；补失败空格。价格相同但本次报价更新时同步备注；成功价格变化时展示旧值、新值、报价日期，请用户决定是否更新。当天多行：暂停该日同步并请求合并决策。跨表日期不全可补缺失表，不重复追加其他表。
6. 写前再次读目标区域，确认没有并发变化。七张表各自定位行号，不假设相同行数。失败新采集不得清空已有成功值；新日期缺失品种写空字符串并在备注记录具体原因，不能写0。

## 写入

使用 `sheet range-data-batch-update`，每个单元格一个操作：

```json
{"file_id":"目标ID","worksheet_id":3,"range_data":[{"op_type":"cell_operation_type_formula","row_from":67,"row_to":67,"col_from":0,"col_to":0,"formula":"=DATE(2026,11,6)"}]}
```

示例坐标仅说明格式，实际必须来自刚才的读取。价格 formula 是数值字符串，备注为文本；操作只作用一个单元格。日期使用 DATE 公式并验证显示格式；若显示序列号，按当前 kdocs 格式接口设置日期格式。

- 汇总：日期、1#电解铜、1#电解镍、0#锌锭/上海、1#锡、1#钴/华南、碳化钨、备注。
- 四种 shmet 金属同报价日时：`shmet四品种取MM-DD结算中间价`；不同时逐品种标日期。
- 钴：`shmet华南1#钴MM-DD中间价`。
- 碳化钨：`我的钢铁网MM-DD均价`。
- 分表：日期、价格、来源/报价日期备注。四品种备注 `shmet MM-DD结算中间价`。
- 每次仅串行修改一个工作表；跨表没有事务。记录每张表状态以便恢复。

## 验证和错误恢复

每表写后 `get-range-data` 精确回读刚写范围，核对 DATE 公式/日期值、价格、单位对应列、备注。全部完成后检查当天每表恰好一行，六个价格与汇总一致。

写请求超时或异常返回时先回读同一坐标判断是否成功；禁止直接计算新空行并再追加。对未生效单元格按 kdocs 有限重试规则处理。403/权限错误立即停止，429按恢复时间等待，不换通道绕过。删除重复行不是自动重试操作：必须明确授权，合并验证后才删除，删除响应不明时重新定位日期与内容，不能重复删除原行号。

检查 CLI 外层与内层错误码、result，不以进程返回0推断业务成功。按 kdocs skill 的触发条件获取反馈链接。报告部分完成状态，不把跨表部分写入称作成功。
