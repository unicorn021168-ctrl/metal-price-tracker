# 可替换原定时任务的描述

使用已安装的 metal-price-tracker skill 执行每日金属价格采集。

先读取该技能 SKILL.md，按其中 local-profile 配置运行 collect.py，最多重试失败来源一次。通过 kdocs skill 与 kdocs-cli 连接金山文档《金属价格追踪》，按日期检查七张表并追加或补全，回读验证；已有成功价格不因本次失败被清空，同日重跑不得重复追加。

向用户发送包含金属名称、规格/地区、中间价、报价范围、涨跌、单位、数据来源的 Markdown 表格，注明真实报价日期、失败/恢复情况、CSV 保存情况和云表核对结果。遇到历史重复或成功价格冲突时报告并等待处理，不擅自删除。

安装技能后才替换任务描述；本仓库不会自动修改 WorkBuddy 的定时设置。
